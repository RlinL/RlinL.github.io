# Happy Math Web

Personal HTTPS control interface for Happy, built from upstream pull request
[slopus/happy#1494](https://github.com/slopus/happy/pull/1494) at commit
`45783fb9b5261c8434ad7404eade102fdb1e4b5c`.

Local customizations enable `expMathRendering` by default and expose the
`Claude-Opus-5-hq` and `Claude-Fable-5-hq` model identifiers. The Codex and
Claude processes themselves continue to run on the owner's Mac mini.
